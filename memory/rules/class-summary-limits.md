# Resumo da classe: limites de entrada

## Regra
`Visitantes` deve ser limitado a 50. `Bíblias` e `Revistas` devem ser limitadas à soma de alunos presentes + visitantes.

## Aplicação
A regra deve ser aplicada no frontend da tela de chamada tanto durante a digitação quanto antes do salvamento, para evitar payload inválido e manter o comportamento consistente com o legado.
