# Ordem fixa de exibição das classes

## Regra
A tela de classes deve renderizar, nesta ordem, as classes do cadastro 1: `Cordeirinhos de Cristo`, `Shalon`, `Filhos de Asáfe`, `Mensageiros de Cristo`, `Filhos de Sião` e `Rosas de Saron`.

## Aplicação
- A ordenação visual do front deve seguir essa sequência fixa antes de montar os cards;
- a ordem não deve depender da ordenação alfabética vinda da API;
- a prioridade deve ser preservada mesmo se o backend retornar os registros em outra ordem.
