# Sessão 2026-08-04

## O que foi alterado
- O fluxo de geração do PDF passou a revalidar os dados diretamente no backend antes da montagem do relatório.
- O relatório deixou de confiar no snapshot local do navegador como fonte principal.

## Conhecimento consolidado
- A planilha continua sendo a fonte oficial para relatórios; o localStorage serve apenas como contingência e recuperação rápida.
- A revalidação do PDF deve usar `refreshFromBackend(..., { preferLocal: false })` antes de construir o documento.

## Próximos passos
- Manter a regra de que relatórios e buscas por data devem priorizar a planilha quando o backend estiver disponível.
