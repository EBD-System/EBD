# API versioning

## Decisão

A API oficial do projeto passa a ser exposta em `/api/v1`.

A superfície antiga em `/api` e `/` foi removida.

## Motivo

A versão explícita reduz risco de quebra, deixa claro qual é o contrato oficial e cria um ponto único para evolução futura da API.
