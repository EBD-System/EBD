# Decisão: aliases em português removidos da API

## Decisão

Os aliases em português para recursos principais foram removidos. Os caminhos canônicos em inglês permanecem como interface oficial da API.

## Motivo

A reconstrução do frontend não depende mais da camada de compatibilidade anterior, e manter apenas rotas canônicas reduz manutenção e ambiguidade.
