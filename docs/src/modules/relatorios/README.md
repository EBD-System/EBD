# Módulo de relatórios

Estrutura atual:
- `pages/index.html`: vitrine de módulos de relatórios.
- `presencas/index.html`: fluxo funcional de presença com data única.
- `melhor-aluno-geral/`: lista compacta de alunos com nome, classe e percentual.
- `melhores-classes/`: lista compacta de classes com nome e percentual.
- `melhor-da-classe/`: ranking real com seletor de turma e consulta ao endpoint do backend.
- `relatorio-aluno/`: consulta os alunos da turma selecionada, filtra por nome e baixa o relatório individual de frequência por período.
- `financeiro/`: consulta ao backend real com filtro por período, seleção de turma e total consolidado de ofertas.
